Dashboard - It is an intuitive interface for displaying and analyzing data. 
The project is implemented with a focus on adaptability, which ensures comfortable use on different devices and screens.

Key features:
Adaptive table: Data table that is automatically transformed into cards when you change the width of the screen, providing easy access to information on mobile devices.
Intuitive design: A simple and understandable interface that allows you to quickly find and analyze the data you need.
Interactivity: Data sorting and filtering for convenient analysis.
Cross -platform: The system is designed for correct operation on different platforms and devices.

Technologies used:
HTML: Semantic page structure to ensure accessibility and SEO optimization.
SCSS: Stylization using variables, mixes and investments for easy modification and code support.
JavaScript: Interactivity and functionality, including adaptive tables and cards.

Impressions and achievements:
This project has become a demonstration of my web development skills and adaptive design. 
The implementation of an adaptive cards table emphasizes my approach to creating convenient and functional interfaces that provide excellent custom experience on different devices.
